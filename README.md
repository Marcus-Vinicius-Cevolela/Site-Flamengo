## 📖 Sobre o projeto

### 🇧🇷 Português

O **Site Flamengo** é uma aplicação web desenvolvida para apresentar, de forma moderna e interativa, diferentes aspectos da história do **Clube de Regatas do Flamengo**.

O projeto foi criado como uma oportunidade de colocar em prática conceitos de **HTML5, CSS3 e JavaScript**, trabalhando principalmente com organização de layout, responsividade, manipulação do DOM, componentes interativos, filtros, carrosséis e apresentação dinâmica de informações.

A proposta foi transformar um conteúdo predominantemente informativo em uma experiência visual mais envolvente, utilizando uma identidade inspirada nas cores e na história do clube.

### 🇺🇸 English

**Site Flamengo** is a web application created to present different aspects of **Clube de Regatas do Flamengo** through a modern and interactive experience.

The project was developed to practice **HTML5, CSS3 and JavaScript**, with a strong focus on layout organization, responsive design, DOM manipulation, interactive components, filters, carousels and dynamic content rendering.

The goal was to transform informational content into a more engaging visual experience inspired by Flamengo's colors, history and identity.

## ✨ Funcionalidades

### 🏠 Página inicial

* Hero section com identidade visual do Flamengo
* Navegação entre as principais seções
* Apresentação institucional do clube
* Destaques sobre o Maracanã, Ninho do Urubu e a Nação Rubro-Negra
* Layout responsivo

### 📜 História

Apresentação da trajetória do Clube de Regatas do Flamengo, desde sua fundação como clube de remo até sua consolidação como uma das maiores instituições esportivas do Brasil.

### ⚽ Elenco

Seção dedicada ao elenco do Flamengo, com:

* Listagem dos jogadores
* Filtros por posição
* Categorias de:

  * Goleiros
  * Zagueiros
  * Laterais
  * Meio-campistas
  * Atacantes
* Ordenação por número da camisa
* Exibição dinâmica das informações

### ⭐ Ídolos da Nação

Área dedicada a jogadores marcantes da história do clube.

A seção utiliza elementos interativos para apresentar informações como:

* Jogos
* Gols
* Conquistas
* Informações pessoais
* Período no clube
* História dos jogadores

### 🏆 Títulos

Uma seção dedicada às principais conquistas do Flamengo, apresentadas através de uma interface visual e interativa.

### ⭐ Homenagem aos 10

Uma das partes mais importantes do projeto.

A seção presta homenagem aos **10 jovens atletas das categorias de base do Flamengo que faleceram no incêndio ocorrido no Ninho do Urubu em 2019**.

A proposta é preservar a memória dos jovens através de uma apresentação visual e respeitosa.

### 🖼️ Galeria

Galeria de imagens com filtros por categoria:

* Todos
* Títulos
* Gols
* Torcida
* Comemorações

Também possui cards com informações relacionadas aos momentos apresentados.

## 🎨 Interface e identidade visual

A interface foi desenvolvida utilizando como base a identidade visual do Flamengo.

### Paleta principal

* 🔴 Vermelho — `#E00000`
* ⚫ Preto — `#000000`
* ⚪ Branco — `#FFFFFF`

A combinação de cores foi utilizada para criar contraste entre as seções e reforçar a identidade visual rubro-negra.

O projeto também utiliza diferentes recursos de **CSS3**, como:

* Gradientes
* Sombras
* Transições
* Hover effects
* Cards
* Overlays
* Animações
* Layouts flexíveis

## 🎯 Objetivo do projeto

### 🇧🇷

O principal objetivo foi desenvolver uma experiência web completa utilizando tecnologias fundamentais do Front-End, colocando em prática conceitos de estruturação, estilização, responsividade e interatividade.

Além do aspecto técnico, o projeto também buscou trabalhar **organização de informação e experiência do usuário**, transformando diferentes conteúdos históricos em uma interface visualmente agradável e fácil de navegar.

### 🇺🇸

The main goal was to build a complete web experience using core Front-End technologies while practicing structure, styling, responsiveness and interactivity.

Beyond the technical aspects, the project also focused on **information organization and user experience**, transforming historical content into a visually engaging and easy-to-navigate interface.
